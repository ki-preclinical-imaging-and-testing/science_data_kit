# Future Roadmaps

## Overview
This directory contains roadmaps that are planned for future development but are not currently active priorities. These roadmaps represent important strategic directions for the Science Data Kit but have been temporarily deprioritized to focus on fundamental frontend/backend integration work and user experience optimization.

## Roadmap Status

### Knowledge Graph Documentation System
The Knowledge Graph Documentation System transforms the Science Data Kit into an AI-navigable scientific software platform. This advanced feature set has been moved to future development to prioritize fundamental platform stability and user experience.

**Status**: Planning - The Knowledge Graph Documentation System roadmap has been defined and is divided into six phases:

1. **Phase 1: Foundation** - Establishing the core infrastructure for the knowledge graph system
2. **Phase 2: Core Integration** - Integrating the knowledge graph system with existing documentation systems and tools
3. **Phase 3: AI Navigation** - Enabling AI agents to navigate and understand the codebase through the knowledge graph
4. **Phase 4: User Interfaces** - Creating tools for human interaction with the knowledge graph
5. **Phase 5: Advanced Features** - Adding advanced capabilities to the knowledge graph system
6. **Phase 6: Ecosystem** - Platform maturation and broader adoption

**Supporting Documentation**:
- Knowledge Graph Vision - Detailed vision document explaining the "AI-native software architecture" concept
- Knowledge Graph Technical Specification - Technical specification covering documentation markup standards, schema design, and integration requirements
- Knowledge Graph Examples - Concrete examples showing before/after documentation examples, sample AI queries, and tagging examples

### Strategic Enhancements
The Strategic Enhancements roadmap outlines a comprehensive plan for platform maturation, community adoption, and long-term sustainability. While valuable, these enhancements have been moved to future development to focus on core platform stability and user experience.

**Status**: Planning - The Strategic Enhancements roadmap has been defined and is divided into three phases:

1. **Phase 1: Foundation Enhancements** - Establishing core capabilities for documentation automation, workshop feedback integration, and domain branch templates
2. **Phase 2: Community and Performance** - Implementing performance monitoring, AI assistant training, and community contribution frameworks
3. **Phase 3: Platform Expansion** - Completing domain branch templates and adding cross-platform deployment and scientific workflow integration

## Timeline for Return to Active Development

These roadmaps are expected to return to active development after the completion of the Design/UX phase and the Repository Reorganization roadmap. The estimated timeline is:

1. **Knowledge Graph Documentation System**: Expected to return to active development after the Design/UX phase is completed and frontend-backend integration is thoroughly validated. Estimated timeline: 2-3 months.

2. **Strategic Enhancements**: Expected to return to active development after the Knowledge Graph Documentation System foundation is established. Estimated timeline: 3-4 months.

## Integration with Current Development

While these roadmaps are not currently active, the architectural decisions made in current development work will continue to support the future implementation of these advanced features. The Design/UX phase will establish a solid foundation for these future enhancements by ensuring:

1. Frontend components are thoroughly tested and optimized
2. Backend-frontend integration is robust and well-documented
3. User experience is polished and intuitive
4. Workshop materials and documentation are comprehensive

This approach ensures that when these future roadmaps return to active development, they will build upon a solid, well-tested platform foundation.

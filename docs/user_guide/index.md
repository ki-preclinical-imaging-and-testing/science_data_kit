## Getting Started

The Science Data Kit (SDK) is designed to help scientists and researchers manage, analyze, and visualize their data. It provides a unified interface for accessing data from various sources, transforming and integrating that data, and analyzing it using a knowledge graph approach.

To get started with the SDK, you'll need to:

1. Install the SDK
2. Set up your environment
3. Create a session
4. Connect to data sources
5. Transform and analyze your data

This guide will walk you through each of these steps and provide detailed information on the various features and capabilities of the SDK.

## Core Concepts

The Science Data Kit is built around several core concepts:

- **Session Management**: The SDK provides robust session management capabilities, allowing you to save and restore your work environment, including server connections, data sources, and pipelines.
- **Data Sources**: The SDK supports various data sources, including Office 365, Dropbox, Google Drive, and local storage.
- **Data Transformation**: The SDK provides configurable pipelines for transforming and mapping data into a knowledge graph.
- **Database Operations**: The SDK includes advanced database features, such as query caching, parameterized query templates, and pagination for large result sets.
- **Data Modeling**: The SDK provides tools for versioning data models, managing relationships, and validating data.
- **API Layer**: The SDK includes a comprehensive API layer for easier integration with external systems and applications.
- **Integration Capabilities**: The SDK supports integration with various platforms, including NExtSEEK and FAIRDOM-Hub.
- **Jupyter Notebook Integration**: The SDK provides templates and utilities for working with Jupyter notebooks.

Please refer to the individual sections for more detailed information on each of these concepts.

## Data Sources

The Science Data Kit supports various data sources, including:

- **Office 365**: Access data from Microsoft 365 services, including OneDrive, Excel, and SharePoint.
- **Dropbox**: Access CSV and Excel files stored in Dropbox.
- **Google Drive**: Access CSV and Excel files stored in Google Drive, with special handling for Google Sheets.
- **Local Storage**: Access CSV and Excel files stored on the local file system or network mountpoints.

Please refer to the [Data Sources Guide](data_sources.md) for detailed information on how to connect to and use these data sources.

## Data Transformation

The Science Data Kit provides configurable pipelines for transforming and mapping data into a knowledge graph. These pipelines support:

- **Tabular Data Mapping**: Convert tabular data (e.g., CSV, Excel) into nodes and relationships for a knowledge graph.
- **File Tree Processing**: Process directory structures and file metadata, creating nodes for directories and files and relationships between them.
- **Data Validation**: Validate data against a set of rules to ensure data quality before further processing or loading into a knowledge graph.
- **Pipeline Templates**: Use templates for common data transformation scenarios.

Please refer to the [Data Transformation Guide](data_transformation.md) for detailed information on how to use these features.

## Database Operations

The Science Data Kit includes advanced database features, such as:

- **Query Caching**: Cache database queries for improved performance.
- **Parameterized Query Templates**: Define reusable query templates with named parameters, validation, and documentation.
- **Query Logging and Performance Metrics**: Track and analyze query execution times, cache hits/misses, and other performance data.
- **Pagination for Large Result Sets**: Retrieve large sets of nodes and relationships with pagination support.

Please refer to the [Database Operations Guide](database_operations.md) for detailed information on how to use these features.

## Data Modeling

The Science Data Kit provides tools for:

- **Versioning Data Models**: Create versioned entities with support for schema versioning, migration, and backward compatibility.
- **Managing Relationships**: Define and work with complex relationship patterns, such as paths, trees, and graphs.
- **Data Migration**: Migrate data between different schema versions.
- **Complex Property Types**: Define and validate complex property types, including nested objects, arrays, and specialized types.
- **Data Validation**: Define and apply validation rules to data.

Please refer to the [Data Modeling Guide](data_modeling.md) for detailed information on how to use these features.

## API Layer

The Science Data Kit includes a comprehensive API layer for easier integration with external systems and applications. This includes:

- **RESTful API Endpoints**: Access SDK functionality through RESTful endpoints.
- **Authentication and Authorization**: Secure your API with token-based authentication and role-based access control.
- **API Documentation**: Access comprehensive API documentation using Swagger UI.
- **Rate Limiting and Throttling**: Control API usage with configurable rate limiting.
- **Client Libraries**: Use Python and JavaScript client libraries for interacting with the SDK API.
- **Command-Line Interface**: Access SDK functionality from the command line.

Please refer to the [API Layer Guide](api_layer.md) for detailed information on how to use these features.

# Science Data Kit Video Tutorials

This directory contains scripts, metadata, and resources for the Science Data Kit video tutorials. These tutorials provide visual demonstrations of key features and workflows in the Science Data Kit.

## Directory Structure

- `scripts/`: Contains the scripts used for recording the video tutorials
- `metadata/`: Contains metadata files for each video tutorial, including descriptions, timestamps, and keywords
- `resources/`: Contains additional resources used in the video tutorials, such as sample data files or images

## Available Video Tutorials

1. **Database Operations Tutorial**: Demonstrates how to use the database operations functionality in the Science Data Kit
2. **Preclinical Challenge Tutorial**: Guides users through analyzing a realistic preclinical cancer research dataset
3. **Data Transformation Tutorial**: Shows how to transform data between different formats using the Science Data Kit
4. **Data Visualization Tutorial**: Illustrates how to create static and interactive visualizations with the Science Data Kit

## Recording Guidelines

When recording video tutorials, please follow these guidelines:

1. Use a screen resolution of 1920x1080 for recording
2. Speak clearly and at a moderate pace
3. Follow the script but feel free to add additional explanations where helpful
4. Keep videos between 5-15 minutes in length
5. Include captions for accessibility
6. Begin with an introduction and end with a summary
7. Include on-screen annotations to highlight important elements

## Usage

The video tutorials are intended to complement the written documentation and Jupyter notebook tutorials. They provide a visual demonstration of key concepts and workflows, making it easier for users to understand how to use the Science Data Kit effectively.

Links to the video tutorials are provided on the workshop page and in the documentation.
